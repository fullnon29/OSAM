# 오샘 서류 정리 도구 (윈도우)

내 컴퓨터의 수급자 서류 폴더를 통째로 읽어 시스템에 올립니다.
웹 브라우저로는 폴더를 통째로 읽을 수 없어 이 프로그램이 필요합니다(요구사항 11).

서류를 읽고·판별하고·수급자를 알아내는 부분은 웹앱과 **같은 코드**를 씁니다
(`src/lib/documents/`). 화면만 다를 뿐 동작과 결과는 웹과 동일합니다.

## 처음 한 번 설정

접속 열쇠를 실행파일에 넣지 않았습니다. 실행파일에 박아 배포하면 유출 시
회수할 수 없기 때문입니다. 대신 아래 위치에 설정 파일을 둡니다.

```
C:\Users\<사용자>\AppData\Roaming\오샘 서류 정리 도구\settings.json
```

```json
{
  "url": "https://<프로젝트>.supabase.co",
  "key": "<Supabase secret key>"
}
```

## 쓰는 법

1. **폴더 선택** — 서류가 든 폴더를 고릅니다(하위 폴더까지 모두 찾습니다)
2. **올리기 시작** — 진행률과 건수가 실시간으로 보입니다
3. 중간에 **중지**해도 되고, 다시 실행하면 이어서 진행됩니다

같은 파일은 내용을 기준으로 알아보고 건너뛰므로 **여러 번 실행해도 안전**합니다.
파일명이나 위치가 바뀌어도 같은 파일이면 중복으로 올라가지 않습니다.

수급자 연결은 **장기요양인정번호가 일치할 때만** 자동으로 합니다.
이름은 동명이인이 있어 잘못 붙으면 엉뚱한 어르신 기록이 되므로,
번호가 없는 서류는 미연결로 두고 사람이 확인하도록 남깁니다.

## 개발

```bash
node desktop/build.mjs                                   # 번들
npx electron desktop/dist/main.js                        # 실행
npx electron-builder --config desktop/builder.yml --win  # 실행파일 생성
```

빌드 출력은 `C:/osam-build/release` 로 나갑니다.
바탕화면 폴더는 클라우드 동기화 대상이라 빌드 중 파일이 잠기기 때문입니다.
